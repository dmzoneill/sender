# Sender

A VB.NET Windows Forms tool for sending a message over TCP.

## What it does

Enter a host, a port number and a message, then click **make tcp connection**.
The program sends the message and shows what the host returned.

## Tech

- Visual Basic .NET (Windows Forms)
- `System.Net.Sockets`

## Building

Open the project in `sender` in Visual Studio and build it. Windows only.
